# 周度均价安全边际策略（独立策略）

本策略于2026-09-12确定参数，入口为 weekly_value_strategy.py，独立结果目录为 weekly_value_results。复用现有BS、ZL、LSM定价及每日行情；单独运行不执行定价、错误定价因子、IC、数据抓取或Git发布。旧月度策略和 weekly_results 内的相对排名研究保留。

## 固定参数

| 项目 | 规则 |
|---|---|
| 估值 | V=(BS+ZL+LSM)/3，S=V/P-1；三模型同日、市价一致，缺一排除 |
| 综合成本 | 单边5bp（0.05%），包含手续费和滑点；按实际成交金额扣一次 |
| 买入余量 | V×(1-c)÷[P×(1+c)]−1≥2%，c=0.0005；原始估值差门槛约2.1021% |
| 多头席位 | 风险筛选后N只，最多floor(N×20%)只；按S降序、代码升序，前20%中不达门槛的席位留空 |
| 小样本 | N<5不新建仓；N足够但只有3只满足买入门槛，可以买3只 |
| 权重 | 多头等权，min(1/入选数,10%)；3只目标30%，其余约70%现金，另扣成交成本 |
| 理论空头 | 共同合格池末20%等权，总目标仓位缩至多头总目标仓位；无多头则不新建空头 |
| 调仓 | 已完成交易周最后交易日冻结信号，下个交易日有效开盘报价模拟成交 |
| 日核算 | 每日持仓、现金、费用、净值及风险检查；周内自然漂移不额外再平衡 |
| 现金与借券 | 现金收益0；空头借券年化3%，按实际自然日计提，独立于交易摩擦 |
| 压力情景 | 单边10/20bp；门槛使用对应成本，安全边际保持2%，不按收益改参数 |

2%是事先确定的研究准入参数，尚未按样本外模型误差校准，不代表已覆盖模型风险。扣费估值余量假设未来按当前模型估值退出，不是预测一周收益。三模型分歧单列，不加未经验证的权重；LSM含ZL价值下限，三个数并非三个独立证据。

## 基本面与事件准入

- 评级≥AA、价格≤150元、纯债溢价≤40%；剩余期限≥半年、余额≥3亿元（缓存30000万元）、上市超过30天。
- 近20个交易日平均成交额≥1000万元，至少15日有观测，信号日成交非零。
- 正股非ST/退市风险；净资产、最近已公告EPS、扣非净利润均为正。
- 非银行资产负债率≤75%、经营现金流为正；银行豁免后两项，行业暴露单独披露。
- 完整跟踪线排除强赎已满足、提示、实施及当时已知半年内退市；未知不视为安全。
- 财务保留报告期、公告日期与来源。只有日期的公告下一交易日生效；后来发现的更正不倒填跟踪历史。

历史研究线缺少完整强赎/ST状态及原始财报版本，不能据当前快照宣称历史安全。它只作为“估值＋基本面研究版”。完整跟踪只从交易前冻结输入的信号开始。

## 开盘买入限制与退出

每次信号冻结模型估值，计算 P_max=V×(1-c)÷[(1+c)×(1+2%)]。下个交易日开盘价超过上限，本次买入或增仓取消，不替补名单，资金留现金。原持仓按周度目标减仓或退出不受买入门槛阻碍。高开只使增仓不合格时，不机械清零原有可保留数量。

停牌、无有效开盘价或单一价格交易日不假定成交。无法退出的原持仓继续记录；最后真实价格仅用于带陈旧天数的估值。每日风险生效后下一交易日尝试退出，不用未来复牌信息预判成交。

理论多空在周度调仓时缩减可交易空头，避免因多头买入失败而新建过大的空头。停牌锁定头寸及周内价格变化仍可造成实际净敞口偏离，报告实际多、空、净敞口。金额平衡不等于贝塔中性，无历史券源验证时仅为理论研究。

5bp按成交金额计入现金扣减，已包含假设滑点，不重复扣佣金或滑点。费用预留按扣费后净资产下界计算，实际仓位可略低于名义目标。当前采用连续份额，没有交易手数、账户最低佣金和盘口容量模型。

## 数据与绩效边界

日行情覆盖2019-01-02至2026-09-11，共1868个交易日；三模型有394个共同周度截面。日线包含开高低收、成交量及成交额。Tushare为主要行情来源，AkShare对应的新浪、东方财富、集思录与巨潮接口用于核对和补充；保留来源、获取时间及原始记录。

核算已验证付息与赎回，包括空头义务。目前已有5笔核验现金流，其他付息尚未全部核验，因此净值不是已认证的完整总收益。无法解释的持仓收盘价缺口会使正式绩效留空，仅保留diagnostic_*；已核验停牌仍使用陈旧估值并注明天数。

收益、波动和最大回撤用日净值计算；另报周胜率、年换手、现金、集中度、银行暴露、年度和滚动窗口。多头基准为000832.CSI，起点使用同一天开盘。起始空仓等待期保留，不能只从第一次盈利交易开始统计。

参数在2026年固定，不把2019年历史回测包装成当时已经运行的样本外记录；历史财报与事件仍有版本和覆盖限制。

## 独立运行

~~~powershell
# 只读取已有输入，运行新策略两类组合及研究/跟踪两条线
python "long-short strategy/weekly_value_strategy.py" --start 2019-01-01

# 只跑历史研究
python "long-short strategy/weekly_value_strategy.py" --start 2019-01-01 --line research

# 成本压力情景，不同配置必须使用不同目录
python "long-short strategy/weekly_value_strategy.py" --transaction-bps 10 --line research --output-dir "long-short strategy/weekly_value_results/stress_10bp"

# 可选完整对照：月度、单模型、基本面和成本，不运行定价或因子脚本
python "long-short strategy/weekly_value_strategy.py" --compare
~~~

参数还有 --end、--model、--frequency、--mode、--long-safety-margin（小数，0.02=2%）、--borrow-rate、--without-fundamentals、--input-dir、--output-dir。月度对照取已完成自然月最后一个现有模型截面，不新造月末估值。

默认目录 weekly_value_results/research 与 tracking。输出 rankings、targets、coverage、每类组合的 daily_nav/trades/holdings/issues、metrics、windows、周报、日净值图和manifest。long_excluded_by 区分风险不合格、余量不足和超过席位；targets 标注计划与待开盘状态，不冒充交易流水。

跟踪信号保留参数和冻结时间；新增日账本先校验历史一致性，相同输入重复运行不改写、不重复交易。旧 weekly_results 与六因子研究不覆盖。正常周更新已接入新入口；手动策略回测不调用包含定价、因子或发布动作的总流水线。
