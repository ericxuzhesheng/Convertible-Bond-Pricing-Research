# 多接口实测记录

2026-09-12使用AkShare 1.18.94实际测试。依赖安装在项目tmp/akshare-deps，不改变现有定价环境；生产数据补取使用同一公开接口协议和requests。

|接口|实测结果|用途与边界|
|---|---|---|
|Tushare cb_daily/index_daily|1,868个交易日|策略日行情与同区间基准|
|Tushare cb_call|权限不足|错误原样保留在acquisition.json；没有绕过权限|
|AkShare bond_zh_cov_info，东方财富基本信息|指定券和批量均成功；批量1,052只，813条赎回公告|历史公告日进入风险检查；执行日期不是直接认定的实际到账日|
|AkShare bond_zh_cov_info，重要日期|通威15条|包含发行、上市、停止交易日期，不能当作完整付息表|
|AkShare bond_zh_hs_cov_daily，新浪|通威227日与Tushare OHLC完全一致；通裕停牌两日两源均无报价|独立日行情核验；不填造停牌开盘价|
|AkShare bond_cb_redeem_jsl，集思录|315只|当前强赎快照，不能倒推2019年安全状态|
|AkShare bond_cov_issue_cninfo，巨潮发行|2019年127条|发行资料，部分返回日期存在历史回填风险，不用于收益记账|
|AkShare stock_zh_a_disclosure_report_cninfo，巨潮公告|通威原公告、2020年135条付息索引成功；同协议批量索引合计2,360条|索引保留原文链接；逐份核验后才进入现金流|

通威、圆通、曙光赎回现金流以及节能2022/2023票息已由公司原公告核验。节能2024原公告摘要与正文的兑息年份不一致，保留待核验。通裕2025-04-30、05-06停牌由原公告说明，属于已解释的陈旧估值，不可据此模拟卖出。

历史最终赎回公告不是完整的历史触发/豁免记录，首次财报历史也不是原始发布版本。现阶段结果仍是研究估计，未认证完整总收益。
